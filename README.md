# hxwl-11 验光看板 / 镜架售后调整台

视力、屈光参数与复查处方对比；镜架交付后的鼻托松脱、镜腿变形、焊接返修售后流程。

## 技术栈

React + Vite + TypeScript + CSS

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5111

## 售后调整台

按「档案 / 判定 / 保存 / 页面」四层组织（`src/aftersales/`）：

- `types.ts` 档案层：案件、版本、故障、配件需求、调整位时段、配件台账结构
- `rules.ts` 判定层：保修（购买日起 12 个月）、调整位撞档、备件占用、
  超保修材料费、状态流转、确认锁定、返工重开等纯函数规则
- `storage.ts` 保存层：localStorage 仓库（建案、登记、提交判定、确认、
  返修、完成、返工重开、入库），首次加载带演示档案
- `AfterSalesDesk.tsx` + `components/` 页面层：建案栏、案件列表、
  待处理编辑判定、顾客确认、版本历史、配件台账

业务规则：

- 按顾客代号、镜架编号、购买日建案；登记故障与配件需求，安排调整位时段
- 调整位撞档或备件不足 → 留在「待处理」并列明原因，入库/改期后可重新提交
- 提交通过 → 「待确认」；超出保修范围按配件台账牌价列明材料费
- 顾客勾选确认后，故障、配件、费用锁定（只读），备件同时预留扣减
- 已完成案件返工 → 重开新版本并记录返工原因，旧版本原样保留可查

验光看板保留在「验光看板」页签（`src/optometry/OptometryBoard.tsx`）。
