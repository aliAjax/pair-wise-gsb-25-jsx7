# hxwl-11 视光门店工作台

验光看板 + 镜架售后调整台

## 技术栈

React + Vite + TypeScript + CSS

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5111

## 功能

### 验光看板

- 领域指标看板
- 角色和分类筛选
- 专业字段录入区
- 示例记录列表

### 售后调整台（src/afterSales）

替代原先记录鼻托松脱、镜腿变形、焊接返修的便签：

- **建案**：按顾客代号、镜架编号、购买日登记，勾选故障类别并登记配件需求
- **排班**：选择调整位与时段；同一工位同一天时段相交即撞档
- **待处理**：调整位撞档或备件不足时案件留在待处理，可修改后重新判定
- **保修判定**：购买日起 12 个月内为保内（免材料费）；保外按配件用量列明材料费
- **顾客确认**：保外材料费须勾选"顾客点头确认"后才能确认返修
- **锁定**：确认返修后故障、配件、费用锁定，扣减备件库存
- **返工重开**：已完成案件必须填写返工原因才能重开；配件回补，重新确认后生成新版本
- **版本记录**：每次锁定形成一版，旧版本原样保留可查
- 数据保存在浏览器 localStorage，可用"恢复演示档案"重置

## 分层结构

档案、判定、保存、页面严格分开：

| 层 | 文件 | 职责 |
| --- | --- | --- |
| 档案 | `src/afterSales/types.ts`、`catalog.ts` | 领域类型、故障目录、保修政策、种子数据 |
| 判定 | `src/afterSales/rules.ts` | 纯函数：保修、撞档、备件、报价、锁定/重开规则 |
| 保存 | `src/afterSales/storage.ts` | localStorage 读写、建案/确认/完成/重开与库存变更 |
| 页面 | `src/afterSales/AfterSalesDesk.tsx` | React 表单、案件队列、版本记录展示 |

后续可继续扩展 IndexedDB、权限、后端 API 和复杂图表。
